# Web Developer Roadmap

این پروژه یک وب‌سایت تعاملی با عنوان **Web Developer Roadmap** است که مسیر یادگیری و توسعه وب را به صورت بصری و ساده نشان می‌دهد.  
وب‌سایت بر پایه **HTML، CSS و JavaScript** ساخته شده است و برای مرورگرهای مدرن بهینه شده است.

---

## **ویژگی‌ها**

- نمایش مسیر یادگیری توسعه وب به صورت مرحله‌ای  
- طراحی مدرن و واکنش‌گرا (Responsive)  
- رابط کاربری ساده و قابل فهم برای همه سطوح  
- کاملاً **فرانت‌اند**، بدون نیاز به سرور  

---

## **نحوه استفاده / کلون پروژه**

1. فایل‌ها را کلون کنید:
git clone https://github.com/aarazshojai/web-developer-roadmap.git

2. وارد پوشه پروژه شوید:
cd web-developer-roadmap

3. فایل `index.html` را با مرورگر باز کنید.

---

## **ساختار فایل‌ها**

- `index.html` – فایل اصلی HTML  
- `style.css` – استایل و طراحی سایت  
- `script.js` – منطق و تعاملات سایت  

---

## **گسترش پروژه**

- افزودن مسیرهای پیشرفته‌تر و منابع بیشتر  
- بهبود طراحی و تجربه کاربری (UI/UX)  
- اضافه کردن حالت شب و روز (Dark/Light Mode)  
- ذخیره و بازخوانی پیشرفت کاربران با **LocalStorage** یا دیتابیس
