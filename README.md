# web-developer-roadmap
# Kimi Chat – Simple Web Chat App

**Kimi Chat** یک اپلیکیشن چت ساده و تعاملی است که با **HTML، CSS و JavaScript** ساخته شده است. این پروژه به عنوان نمونه‌ای از طراحی رابط کاربری مدرن و شیشه‌ای (Glassmorphism) و منطق پایه چت ایجاد شده است.

---

## **ویژگی‌ها**

- طراحی مدرن با **شیشه‌ای و مات** (Glassmorphism)  
- پشتیبانی از پیام‌های کاربر و پاسخ‌های ساده ربات  
- اسکرول خودکار در چت  
- ارسال پیام با **کلیک روی دکمه یا Enter**  
- کاملاً **فرانت‌اند**، بدون نیاز به سرور  

---

## **نحوه استفاده**

1. فایل‌ها را دانلود یا کلون کنید:
git clone https://github.com/USERNAME/kimi-chat.git

2. وارد پوشه پروژه شوید:
cd kimi-chat

3. فایل `index.html` را با مرورگر باز کنید.

> برای تجربه آنلاین، می‌توانید از **GitHub Pages** استفاده کنید.

---

## **ساختار فایل‌ها**

- `index.html` – فایل اصلی HTML  
- `style.css` – استایل و طراحی اپلیکیشن  
- `script.js` – منطق و تعاملات چت  

---

## **گسترش پروژه**

- اضافه کردن پاسخ‌های هوشمندتر با استفاده از **AI یا API**  
- پشتیبانی از **تم شب و روز**  
- ذخیره پیام‌ها در **LocalStorage** یا دیتابیس
